## 📊 Featured Project

### 🛒 Superstore Sales & Profit Analysis

A business-focused data analysis project using the **Sample Superstore dataset** to identify profitability trends, return patterns, customer opportunities, and operational improvements.

### 🔍 Business Questions Analyzed

**1. Regional Profitability**

* Identified the region generating the highest profit.
* Compared regional performance against targets.

**2. Category Return Rate**

* Calculated return rates across product categories.
* Identified **Furniture** as the category with the highest return rate.

**3. Average Order Value**

* Compared Average Order Value across sales channels.
* Identified differences in customer order behavior.

**4. Discount vs Profit**

* Analyzed the relationship between discount percentage and profit.
* Evaluated how discounting can affect profitability.

**5. Customer Loyalty**

* Recommended retention strategies for **Platinum and Gold customers**.
* Focused on personalized offers, rewards, and customer retention.

**6. Operational Improvements**

* Recommended actions for products and categories with high return rates.
* Suggested improvements in product quality, packaging, descriptions, and supplier monitoring.

### 🧰 Tools Used

`Python` `Pandas` `NumPy` `Matplotlib` `Google Colab`
